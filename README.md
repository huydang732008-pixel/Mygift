# Happy Monthsary website

Mở `index.html` bằng trình duyệt để xem.

## Cấu trúc
- `index.html` — 5 màn hình + các vùng click.
- `style.css` — nền, responsive và hiệu ứng chuyển màn hình.
- `script.js` — điều hướng.
- `assets/page0.png` ... `page4.png` — artwork theo các ảnh mẫu bạn đã gửi.

## Điều hướng
1. Trang bìa → bấm phong thư.
2. "For you" → Letter / Flower / A song for you.
3. Mỗi trang có nút BACK để quay lại.
4. Ở trang Song, vùng video mở MV "Nahanap Kita - Amiel Sol" trên YouTube.

## Tùy chỉnh
Nếu bạn gửi cho tôi ảnh gốc của phong thư, hoa, gấu, ảnh đôi... (thay vì ảnh chụp màn hình), tôi có thể dựng lại từng thành phần bằng HTML/CSS để website sắc nét và responsive hơn thay vì dùng artwork chụp màn hình.
